# Запуск приложения Xavfsiz Import

Запуск займёт около часа. Лучше делать с компьютера: на телефоне GitHub не умеет загружать папки. Понадобятся 3 бесплатных аккаунта: GitHub, Supabase и Vercel.

## Шаг 1. Узнай свой Telegram ID

1. Найди в Телеграме бота **@userinfobot** и нажми «Старт».
2. Он пришлёт число **Id**, например `512345678`. Сохрани его: это твой ключ к админке.

## Шаг 2. Загрузи файлы на GitHub

1. Распакуй архив `xavfsiz-import.zip`.
2. Зайди на **github.com** и зарегистрируйся (Sign up).
3. Нажми **+** вверху → **New repository**. Название: `xavfsiz-import`, выбери **Private** и нажми **Create repository**.
4. На странице нового репозитория нажми ссылку **uploading an existing file**.
5. Открой распакованную папку `xavfsiz-import` и перетащи в окно браузера **всё её содержимое**, включая папки `api` и `lib`. Важно перетащить файлы из папки, а не саму папку: `index.html` должен лежать в корне.
6. Внизу нажми **Commit changes**.

## Шаг 3. Создай базу в Supabase

1. Зайди на **supabase.com** → **Start your project** → войди через GitHub.
2. Нажми **New project**: название `xavfsiz-import`, придумай пароль базы (сохрани его), регион **Frankfurt (eu-central-1)** — он ближе всего к Ташкенту. Нажми **Create** и подожди 1–2 минуты.
3. Слева открой **SQL Editor** → **New query**.
4. Открой файл `supabase.sql` из архива, скопируй весь текст, вставь его в окно и нажми **Run**. Должно появиться «Success». Этот шаг создаёт базу и сразу добавляет 7 модулей и 17 уроков.
5. Скопируй два значения:
   - **Project URL** (вида `https://abcd1234.supabase.co`): кнопка **Connect** вверху или **Project Settings → Data API**.
   - **Secret key**: **Project Settings → API Keys** → в разделе Secret keys нажми «Reveal» и скопируй (начинается с `sb_secret_`). Если там только старые ключи, бери **service_role** во вкладке Legacy.

Secret key никому не показывай: с ним можно прочитать всю базу.

## Шаг 4. Размести приложение на Vercel

1. Зайди на **vercel.com** → **Sign Up** → войди через GitHub.
2. Нажми **Add New… → Project**, найди `xavfsiz-import` и нажми **Import**.
3. **Framework Preset**: выбери **Other**.
4. Раскрой **Environment Variables** и добавь 5 переменных:

| Name | Value |
| --- | --- |
| `BOT_TOKEN` | токен бота от @BotFather |
| `SUPABASE_URL` | Project URL из шага 3 |
| `SUPABASE_SERVICE_KEY` | Secret key из шага 3 |
| `ADMIN_IDS` | твой Telegram ID из шага 1 (несколько админов — через запятую) |
| `WEBHOOK_SECRET` | придумай кодовое слово: только латинские буквы, цифры, `_` и `-`, от 8 символов, например `xi_kalit_7Rq2mZ` |

5. Нажми **Deploy** и подожди 1 минуту.
6. Скопируй адрес приложения (**Domains**), например `https://xavfsiz-import.vercel.app`.

## Шаг 5. Подключи бота

Открой в браузере ссылку, подставив свой адрес и кодовое слово:

`https://xavfsiz-import.vercel.app/api/setup?key=xi_kalit_7Rq2mZ`

Должно появиться четыре зелёные галочки ✅: база, бот, ответ на /start и кнопка «Kurs» в меню бота. Если где-то ❌, посмотри раздел «Если что-то не работает».

## Шаг 6. Проверь и добавь видео

1. Открой @xavfsiz_import_bot, нажми **/start** → **Kursni ochish**.
2. Так как ты админ, тебе сразу открыты все уроки и кнопка **Админка**.
3. Загрузи видео на YouTube: **Создать → Загрузить видео**, в разделе «Видимость» выбери **Доступ по ссылке**. Скопируй ссылку.
4. В приложении: **Админка → Уроки** → выбери урок → вставь ссылку → **Сохранить урок**. Там же можно поменять текст и добавить файлы.
5. Проверь путь ученика со второго аккаунта или телефона друга: заявка → тебе приходит сообщение → **Открыть доступ** → ученику приходит «Tabriklaymiz!».

## Как работать каждый день

- **Новый ученик:** он нажимает «Ariza yuborish», тебе приходит сообщение от бота. После оплаты наличными: Админка → **Заявки** → **Открыть доступ**.
- **Закрыть доступ:** Админка → **Ученики** → **Закрыть доступ**.
- **Прогресс учеников:** во вкладке «Ученики» видно, сколько уроков прошёл каждый.
- **Новый урок или модуль:** Админка → **Уроки** → «+ Добавить урок» / «+ Добавить модуль».

## Если что-то не работает

| Что видишь | Что сделать |
| --- | --- |
| На странице setup: «Не заполнены переменные» | Vercel → проект → **Settings → Environment Variables**: добавь недостающие. Потом **Deployments** → ⋯ у последнего → **Redeploy**. |
| ❌ База данных | Проверь `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` (без пробелов) и выполни шаг 3.4 |
| ❌ Бот: неверный BOT_TOKEN | Скопируй токен из @BotFather заново (команда `/token`), обнови переменную, сделай Redeploy |
| Бот не отвечает на /start | Ещё раз открой ссылку из шага 5 |
| Нет кнопки «Админка» | В `ADMIN_IDS` должен быть твой ID из шага 1. После правки — Redeploy |
| Не приходят сообщения о заявках | Нажми /start в боте со своего аккаунта: бот не может написать первым |
| «Sessiya eskirdi» в приложении | Закрой приложение и открой заново через бота |
| Файл не загружается | Размер до 50 МБ. Убедись, что SQL из шага 3 выполнен полностью |

После любого изменения переменных в Vercel обязательно делай **Redeploy**.

## Сколько это стоит

- **Supabase:** бесплатного плана хватит для старта. Бесплатный проект может уйти «в сон», если им долго никто не пользуется: тогда его можно разбудить в панели Supabase.
- **Vercel:** бесплатный план (Hobby) по правилам Vercel только для некоммерческих проектов. Платный курс — коммерческий, поэтому перед началом продаж переключись на **Pro: $20 в месяц**. Тестировать можно бесплатно.
- **YouTube и Telegram:** бесплатно.

## Безопасность

- Если когда-нибудь поменяешь токен бота (`/revoke` в @BotFather), обнови `BOT_TOKEN` в Vercel, сделай Redeploy и снова открой ссылку из шага 5.
- Видео с доступом по ссылке ученик теоретически может переслать. Если это станет проблемой, видео можно перенести на Kinescope с защитой, а приложение доработать.
